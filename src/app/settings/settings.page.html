Scheduling

Use stored sessions
Every session is a real booking, and each package keeps exactly as many upcoming sessions as it has sessions left — excused and unrecorded ones get a makeup booked automatically. Off = the original weekly-pattern calendar. Switching back and forth changes nothing that's saved.
Move packages onto stored sessions
Copies each active weekly package's current calendar (past and upcoming, reschedules included) into stored sessions, then books any owed session that has no date. Only adds — packages, attendance and reschedules are left exactly as they are. Packages already moved are skipped.

Scoring

Rescore levels without the weighted pull-up
Strength is now the average of deadlift, squat and bench, and cardio uses an 800 m run. This recalculates every saved assessment, pending submission, goal and leaderboard level from its own results. It then adds one record dated today for each athlete, holding their most recent results, so everyone's newest entry shows where they are today. Nothing is deleted: the pull-up and 2-minute run numbers stay on each record, and the previous level and rank are kept beside the new ones. Running it again changes nothing further.
